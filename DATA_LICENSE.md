# Dataset attribution and transformations

Helwig, N., Pignanelli, E., & Schütze, A. (2015). *Condition monitoring of hydraulic systems* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5CW21.

Source record: https://archive.ics.uci.edu/dataset/447/condition+monitoring+of+hydraulic+systems

License: Creative Commons Attribution 4.0 International (CC BY 4.0): https://creativecommons.org/licenses/by/4.0/

The bundled measurements and source documentation originate from this dataset. Changes: per-cycle statistical feature extraction; selection of 14 physical channels; one original sample per second for UI traces; numeric type conversion; JSON/NPZ packaging. No synthetic sensor values were introduced. Model outputs, derived features and investigation text are not original author annotations. No endorsement by the dataset authors or UCI is implied.

The full-rate example preserves original numeric values for one measured cycle. Original source documentation is included as UCI_description.txt and UCI_documentation.txt. The application source has a separate MIT license.
